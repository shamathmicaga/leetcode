## Problem: Valid Anagram (Easy)

**Link:** https://leetcode.com/problems/valid-anagram/

### Approach

Count the frequency of each character in both strings and compare the frequencies. If all character counts are equal, the strings are anagrams.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The strings must contain the same characters with the same frequencies to be valid anagrams.
